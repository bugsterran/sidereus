# scripts

- `check.sh [--fast|--full]` — the one gate. Steps, fail-fast: py_compile (`/usr/bin/python3`), `node --check`, `bash -n`, PAGE assembly, leak scan, unit tests, screen check. Last line is `PASS`/`FAIL`, exit non-zero on failure.
- `--fast` (< 30s) skips unit tests and the screen check; `--full` (default) runs both (`screen_check.mjs` only if present). Test log path is printed on failure.
- Every run appends one JSON line to `$SIDEREUS_EVIDENCE` (default `$MAILBOX_DIR/evidence.jsonl`) via `evidence_rec.py`: mode, repo, HEAD, dirty, rc, per-step `{name,rc,n,failed,secs}`, screen `{w,lang,ok,diff}` on `--full`. Counts only — no log lines, file or test names. Keeps the last 200 once past 400 lines; a recorder error never changes the gate result.
- `leakscan.py` — scans shipped files (`git ls-files` minus `.distignore`) for your git user.name / user.email / login, real home paths, session UUIDs (outside `tests/`, demo data) and secrets. Skip a line with `leakscan: allow`.
- `fmt_probe.py [--n N] [--json]` — upstream record-format probe: runs Sidereus's own parsers over the N newest real Claude Code / Codex / Gemini session files and names any field that came out empty on all of them (exit 1). A platform with no files is «skip». Run after a CLI upgrade. ⚠Reads live files — never from `check.sh`/`tests/run.sh`; `tests/test_fmt_probe.py` covers it with fixtures.
- `readme_shots.mjs [name…]` — regenerates `docs/images/<name>-{en,ko}.png` (README/GUIDE) from its own `--demo` server and headless Chrome; 1200×750 app view at 2x, framed to 1600×1000. Never touches the live viewer.
  - `pipeline-run` and `harness-flow` are unframed panel crops (1440-wide page, 1x): the Pipelines run canvas down to «Running N», and the «Harness» › «Flow» strip.
- `readme_gif.mjs [--frames DIR]` — animated README hero `docs/images/hero-{en,ko}.gif` (Pipelines view, change-flow stages lighting in turn; 1120×700, ~10s loop, ~400KB) with the same isolation; `--frames` writes three sample frames as PNG. Shared demo/Chrome/CDP helpers: `readme_cdp.mjs`.
- `room_log.py <room> [--since <ISO|ns>] [--from-doc <path> | --doc-dir <dir>] [--bus <path>]` — one mailbox room's messages, oldest first (header line + time · sender · id · `[D]` decision tag · text); `--from-doc` (or `--doc-dir` = `<dir>/<slug>.md`) cuts at that room's last `room-minutes` marker. Input of the `room-minutes` skill; prints message text to the terminal only.
- `mail_react_probe.py --to <id> [--timeout 600] [--from probe-sender] [--poll 1] [--dry-run]` — end-to-end mail reaction probe: one DM `[probe] <nonce>` from a throwaway `probe-*` sender, then read-only watch of the target's read cursor and the bus for a reply with the nonce. One line: target · platform · sent_at · read_after_s · reply_after_s (or `TIMEOUT`). ⚠Writes one live bus row — never from `check.sh`/`tests/run.sh`; `tests/test_mail_react_probe.py` uses a temp dir.
- `pl_report.py --repo <dir> --pipeline <name> [--auto] [--data-dir <dir>]` — pipeline verification report: gate · procedure · result sentences plus the broken / fix-followed passes (short sha · file names) to `eval/<key>/reports/YYYY-MM-DD.md`. `--auto` (spawned by `hooks/pl_flow.py` at run end) skips while the newest report is under 7 days old. Counts and file names only.
- `install-hooks.sh` — sets `core.hooksPath=.githooks` once; `.githooks/pre-commit` then runs `check.sh --fast` and blocks the commit on FAIL (`--no-verify` to bypass).
