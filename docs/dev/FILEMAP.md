# Sidereus — file map

Where each part of the viewer lives. Python module order and ownership: `refactor/STAGE3.md`. Architecture: `docs/ARCHITECTURE.md`.

Sidereus is both the shown name and the code name (package, MCP, launchd label, pipelines).

## Layout

- ★**Python lives in `sidereus/`** (2026-09-23 · split stage 3). `chat_server.py` keeps only `Handler`·`state()`/`_state_body`·PAGE assembly·`main()`; the old top-level names were all re-exported via per-module `__all__`. ⇒ Superseded 09-24: `__all__` removed from 30 modules (only bgtasks·burn·timeline keep it) — read names from the owning module.
  - Map (bottom→top import order): config warn bus claude_roots transcript ident live gitinfo steps agents cards usage otel otel_cache otel_hooks otel_acct projcost bgtasks notes parse ext sessions timeline failures work git_wt git file_owner history quota quota_roots quota_loop agentcost burn awake saver structure_scan (constants·cache·scanner) structure_snap (git·tar·bak snapshots) structure (API·warm-up) attention retro. Reasons and exceptions: `refactor/STAGE3.md`.
  - Shared helpers (09-25~26): `memo.py` `BoundedMemo` (thread-safe LRU + stamp check, no sidereus import) · `timefmt.py` `ymd`/`iso_local`/`iso_z`/`hms` (⚠keep the format bytes identical) · `redact.py` `redact_work` (masks secrets in the work log) · `burn_calc.py` (pure burndown math, no I/O or state).
  - ⚠**One global = one owning module.** `from sidereus.x import NAME` copies the binding, so `global NAME; NAME = …` in another module leaves everyone else on the old value. The only reassigned globals are `_live_cache` (live.py)·`_busy_cache` (live_probe.py) (each read only inside its owning module) — the rest are containers mutated in place. Put a new reassigned global in the same module that reads it.
  - ⚠A module imports **only modules earlier in the order** (no cycles). If a lower-layer function needs a higher-layer name, move the function up or the name down.
  - ⚠`CODE_DIR` in `sidereus/config.py` is **one level above** the file (repo root). `ext-hooks/demo.sh` reads `EXT_PLAT`/`EXT_STATE` from `sidereus/ext_store.py`.

- ★**web/ file map** (2026-09-23 · split stage 2) — `@@INCLUDE js/*.js@@`·`css/*.css@@` = concatenated in name order (NN = order). PAGE·PAGE_BUILD byte-identical to cd07f9f.
