# 컨셉

**Sidereus(시데레우스)** 는 갈릴레이의 『Sidereus Nuncius』(1610, «별의 전령»)에서 이름을 따왔다.
갈릴레이는 망원경으로 하늘을 지켜보고, 달을 위상마다 그리고, 목성의 위성을 밤마다 기록하고, 본 것을 세상에 알렸다.
Sidereus 는 AI 코딩 세션을 상대로 같은 일을 한다.

## 시놉시스

개발자 한 명이 여러 터미널에서 에이전트를 돌린다. Claude Code도 있고 Codex도 있다. 에이전트들은 쉴 새 없이 출력을
쏟아 내지만 그걸 다 읽는 사람은 없다. 뭔가 멈춰야 그제야 고개를 든다.

도구마다 보여 주는 건 한 조각뿐이다. CLI는 자기 세션만, 대시보드는 토큰만, 앱은 diff만 보여 준다. 전체를 놓고
판단할 곳이 없으니 개발자의 답을 기다리는 요청이 아무도 모르게 묵혀 있기도 한다.

Sidereus는 그 터미널들 옆에 놓여, 한 화면에서 검증하고 판단하고 방향을 잡게 해 준다. 에이전트를 대신 실행하지도, 터미널을 가로채지도 않는다. 대신 두 가지를 확인한다.

- **결과** — 게이트가 정말 통과했는지, 실패하던 테스트가 통과로 바뀌었는지, 그 통과가 유지됐는지, 그리고 그 게이트가 실제 결함을 잡을 수 있기는 한지.
- **과정** — 선언한 단계대로, 고른 에이전트와 모델로 돌았는지. 그리고 지금 각 세션이 무엇을 하고 있는지.

그 중심에 파이프라인이 있다. 순서를 한 번 정해 두면 세션이 그대로 따라가고, 단계마다 진행 상황과 판정의 근거가 된 게이트 증거가 남는다.

에이전트가 개발자를 필요로 하면(답변·권한·승인) 목록 맨 위로 올라온다. 개발자가 처리하거나 그 세션이 끝난 게 확인될
때까지 그 자리에 남는다. 처리는 같은 화면에서 하고, 보낸 내용은 기록으로 남는다. 대화 내용은 이 컴퓨터 밖으로 나가지
않는다. 메타데이터만, 로컬에서, 오프라인으로.

완성품이 아니라 포크해서 넓혀 가는 바탕이다. 작업 방식에 맞으면 쓰면 된다. 안 맞으면 포크해서 고쳐 쓰거나 그냥 두면 된다([프로젝트 운영 방식](../README.ko.md#프로젝트-운영-방식)).

## 방향과 만들지 않을 것

Sidereus 는 관측소다. 대시보드도 ADE 도 아니다.

향하는 곳:
- 에이전트 결과의 검증 층: 파이프라인 단계마다 근거, 그리고 심은 결함 적중률·레드 체크·불안정 판정으로 재는 게이트 품질([PIPELINE.md](dev/PIPELINE.md#evaluation-seeds-red-check-flaky-gates)).
- 나를 기다리는 일을 놓치지 않는 관제 화면. «Attention» 은 여러 벤더의 세션을 한 목록에서 나를 막는 정도대로 줄 세운다(승인 대기, 다음이 열린 질문, 그다음 나머지). 막힘·질문 세션이 목록에서 빠지거나 밀리지 않는지는 전체 점검의 테스트가 지킨다. 누르면 그 세션의 터미널 탭이 앞으로 오고, 지시는 메일박스로 간다.
- 터미널 CLI 를 한 화면에서 보기. Claude Code 는 트랜스크립트로 읽고, Codex CLI·Gemini CLI 는 훅으로 보고받는다. Cursor 등 다른 CLI 도 같은 훅을 쓸 수 있지만 아직 확인하지 않았다.

다음(계획):
- 파이프라인 근거와 게이트 평가를 첫 화면 가운데에.
- Cursor 등 훅으로 보고하는 CLI 를 실제 설치에서 확인하기.
- 근거를 OpenTelemetry GenAI 형식으로 내보내 기존 관측 도구가 읽게 하기. 그 도구를 대신하지 않고 데이터를 대 준다.

만들지 않을 것: 에이전트 실행, worktree, diff→PR 흐름, 클라우드 실행, 팀·조직 거버넌스, 대화 추적.
다른 도구가 잘하고 있고, 모두 «메타데이터만, CLI 를 조종하지 않는다»와 부딪힌다.

## 세 동사

| | 갈릴레이 | Sidereus |
|---|---|---|
| **본다** | 달과 목성의 위성을 밤마다 | 모든 세션을 한 화면에서. 나를 기다리는 것부터 |
| **기록한다** | 위치와 날짜·시각 | 파이프라인 단계, 게이트, 테스트, 커밋, `파일:줄` 근거. «끝났다»가 아니라 «무엇으로 확인했다» |
| **전한다** | 책 | 사람의 지시를 메일박스로 세션에 전하고 기록을 남긴다 |

## 지키는 선

천문학자는 별을 옮기지 않는다.

- 에이전트를 실행하지 않고, 터미널을 열지 않고, 입력을 넣지 않는다. 세션은 사용자의 터미널에서 돈다.
- 대화 내용은 화면에 오르지 않는다. 경로, 세션, 모델, 작업 이름 같은 메타데이터만 보인다.
- git 기록을 쓰지 않고, 허용 목록 밖의 파일에도 쓰지 않는다.

| 부류 | 예 | 역할 |
|---|---|---|
| 조종석 / ADE | Agent Cockpit, Conductor, Vibe Kanban | 그 안에서 에이전트를 돌린다 |
| 훅 대시보드 | claude-code-hooks observability, agents-observe | 이벤트를 읽는다 |
| **관측소** | **Sidereus** | 모든 에이전트를 지켜보고, 근거를 남기고, 지시를 전한다 |

차별점은 여러 플랫폼을 한 하늘에서 보는 것, 근거가 붙는 파이프라인 단계, 기록이 남는 전달, 메타데이터만 쓰는 것이다.

## 모습과 말투

- **마크:** 갈릴레이가 『Sidereus Nuncius』에 그린 달. 거친 명암 경계선, 바다, 빛나는 봉우리. 아이콘은 그의 상현달 도판이고, 앱의 마크는 오늘 밤의 위상을 보여 주며 마우스를 올리면 위상과 월령이 나온다. 연결이 끊기면 밝은 부분이 흐려지고 원판 테두리가 빨개진다.
- **색:** 어두운 밤하늘에 달의 밝은 면은 상아색, 밤인 면은 슬레이트색. 강조색은 절제한다. AI 반짝이와 산호색은 피한다.
- **움직임:** 움직이는 것은 하나, 나를 기다리는 것뿐이다. 나머지는 조용히 둔다.
- **말투:** 관측 일지. 언제, 무엇을 봤고, 무엇으로 확인했는지만 쓴다. 과장하지 않는다.

## 하지 않는 것

- ⚠ 터미널, 에이전트 실행, git 쓰기를 코어에 넣지 않는다. 요청이 쌓이면 기본은 꺼 둔 확장으로만 붙인다.
- ⚠ 실제 플랫폼 로고를 마크에 넣지 않는다. 플랫폼의 다양성은 로고가 아니라 지도 위에서 보여준다.
- ⚠ 세션·변경·게이트를 등급 하나로 줄이지 않는다. «Attention» 점수는 목록 순서만 정하고, 보안 결과는 표준 스캐너를 프로젝트 설정(없으면 도구 기본값)으로 돌린 것을 `파일:줄` 과 함께 보여준다. 판정이 아니라 사실과 근거를 보여준다.
- ⚠ 계정이나 자격 증명을 만들거나, 저장하거나, 바꾸지 않는다. 찾아낸 계정 구성을 그대로 보여준다.
