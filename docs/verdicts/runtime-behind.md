# runtime-behind

## Meaning
A runtime (Python or Node.js) is behind the latest patch in its cycle, or its cycle reached end of life.

## Why it matters
Patch releases carry security fixes; an end-of-life cycle gets none.

## Who acts
self

## Next step
Upgrade with Homebrew (`brew upgrade python@3.x` or `brew upgrade node`), then restart the sessions or tools that use it.
